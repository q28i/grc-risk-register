## 1. Objectives & Rationale

1. **One-Click User Onboarding**:
   - Provide a double-clickable launcher (`Start GRC Risk Register.bat`) allowing any user to start the application with zero command-line interaction.
   - Automatically locate project directory, spawn an independent background server, poll for true HTTP readiness, open the default browser at `http://127.0.0.1:8000`, and cleanly terminate the launcher script while leaving the web application running.

2. **Duplicate Server Prevention**:
   - Perform an initial HTTP health check against `http://127.0.0.1:8000` to detect if the GRC Risk Register is already active.
   - If active, avoid starting duplicate processes and immediately open the browser.

3. **Standalone Native Executable (Optional Convenience)**:
   - Provide `Start GRC Risk Register.exe`, a lightweight (6 KB) native C# GUI launcher compiled using Windows built-in `csc.exe` without third-party frameworks.

4. **Clean Clone Database Initialization**:
   - Ensure a clean repository clone without `.db` files automatically creates and seeds the database upon first run (`init_db()` + `seed_database()`).

5. **Release Hygiene & Privacy Protection**:
   - Maintain a minimal, clean public `README.md` free of credentials or internal developmental logs.
   - Provide a private `README_ADMIN.md` for administrators/evaluators and ensure it is strictly ignored by Git.
   - Standardize `.gitignore` to exclude `.db` files, credentials, local logs, and private planning notes.

## 2. Changes Implemented

### A. Plug-and-Play Launcher (`Start GRC Risk Register.bat`)
- Automatically changes working directory to project root or `Grc Risk Management Code/`.
- Detects Python 3 (`python`, `py -3`, `py`, `pythonw`) with user-friendly error alerts if missing.
- Pre-launch HTTP health check via `urllib.request` against `http://127.0.0.1:8000/`.
- Detached server process spawning (`start "" "%PYTHONW_CMD%" app.py`).
- Active HTTP polling loop (up to 30 attempts with 1-second delay).
- Invokes default web browser via Windows shell URL handler (`start "" "http://127.0.0.1:8000"`).
- Exits cleanly with code 0 while web application persists in background.

### B. Python Server Detachment Hardening (`app.py`)
- Added graceful fallbacks for `sys.stdout` and `sys.stderr` when executing under `pythonw` or detached Windows process groups.
- Wrapped `GRCRequestHandler.log_message` in exception-safe blocks to prevent crashes on invalid console handles.

### C. Native GUI Launcher (`Start GRC Risk Register.exe` & `Launcher.cs`)
- Compiled via built-in Windows .NET compiler `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.
- Zero external runtime dependencies.
- Handles health checks, server launch, polling, and default browser launch seamlessly.

### D. Documentation & Git Privacy Protection
- **Public `README.md`**: Clean overview, features, requirements, quick start guide, testing instructions, and Apache 2.0 license.
- **Private `README_ADMIN.md`**: Administrative and demo credentials (`admin`/`admin123`, `analyst`/`analyst123`, `demo`/`demo123`), capability breakdown, and 29-feature control guide.
- **`.gitignore`**: Excludes `README_ADMIN.md`, `*.db`, `__pycache__/`, `Launcher.cs`, `assets_media/`, and internal staging files.
- **`LICENSE`**: Standard Apache License 2.0.
