# CHG-0005: Executive Dashboard & Printable Risk Register Generator

- **Change ID**: CHG-0005
- **Component**: Dashboard, Reporting & Export Engine
- **Upstream Relationship**: Newly Created Engine
- **Date**: 2026-08-18

---

## 1. Original Behavior
Upstream reporting relied on Odoo QWeb XML templates requiring Wkhtmltopdf binary packages. The dashboard was a standard ERP kanban view without dedicated cybersecurity KPI cards or matrix heatmaps.

## 2. Problem / Reason
1. Wkhtmltopdf frequently breaks across different operating systems (Windows, Linux, macOS).
2. Students need a visual overview (Heatmap matrix, Summary counters) to demonstrate risk posture during viva presentations.
3. Exporting filtered registers to CSV and printing clean management summaries was cumbersome.

## 3. Planned Change
1. Build an executive cybersecurity dashboard featuring:
   - 4 KPI summary cards: Total Assets, Total Risks, Open Risks, High Risks.
   - Interactive $3\times3$ Risk Matrix Heatmap (Likelihood vs. Impact) displaying live risk counts per cell.
   - Risk distribution breakdown by status and severity.
2. Build an in-browser printable risk register report with live filtering by Level, Status, Asset Type, and search keyword, plus direct CSV export.

## 4. Implementation Details
- Created responsive UI components using modern Vanilla CSS (cybersecurity dark mode with subtle glassmorphism and emerald/amber/crimson risk accents).
- Built interactive Heatmap component in JavaScript that updates dynamically upon data changes.
- Implemented `@media print` CSS stylesheet formatting printable pages with clean typography, tables, and organizational metadata.
- Implemented client-side CSV generator for instant data export.
