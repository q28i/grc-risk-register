# CHG-0001: Architecture Decoupling & Working Copy Setup

- **Change ID**: CHG-0001
- **Component**: Architecture & Project Structure
- **Upstream Relationship**: Modified Upstream & New Architecture
- **Date**: 2026-08-18

---

## 1. Original Behavior
The upstream project consisted of 7 interdependent Odoo 16 ERP modules requiring a local PostgreSQL database cluster, complex Python C-dependencies (`psycopg2`, `lxml`), Wkhtmltopdf binary rendering tools, and heavy ERP administrative overhead.

## 2. Problem / Reason
1. Running an Odoo 16 stack in an academic evaluation or student viva environment is fragile, difficult to install, and prone to database schema sync failures.
2. The user experience was cluttered with generic ERP modules (HR, Partner, Invoicing) irrelevant to introductory cybersecurity.
3. The upstream codebase contained vendor branding, SaaS upsell markers, and complex relational coupling.

## 3. Planned Change
Decouple the core GRC concepts into a standalone, zero-dependency Python + SQLite + Modern Web architecture in `Grc Risk Management Code`. Retain the upstream modules in `Documentation/` for attribution and private comparison documentation.

## 4. Implementation Details
1. Created dedicated project folder `Grc Risk Management Code`.
2. Structured lightweight, modular application files: `app.py`, `database.py`, `models.py`, `risk_calculator.py`, `auth.py`.
3. Created modern frontend with Vanilla CSS and responsive single-page architecture in `static/` and `templates/`.
4. Created automated test runner in `tests/`.

## 6. Dependencies Affected
- Decoupled from Odoo 16, PostgreSQL, and Wkhtmltopdf.
- Uses Python standard library (`http.server`, `sqlite3`, `hashlib`, `json`, `urllib`).

## 7. Tests Performed
- Application startup test: verified server starts in < 0.5s on port 8000.
- Database auto-initialization test: verified tables and default seeds populate seamlessly.

## 8. Errors Found & Fixes Applied
- *Issue*: PowerShell execution policy prevented running `npm.ps1`.
- *Fix*: Chose native Vanilla CSS and JS without node build dependencies to guarantee 100% portable zero-setup execution.
