# CHG-0007: Flat Material-Style UI/UX Redesign

- **Change ID**: CHG-0007
- **Component**: Frontend UI / UX Presentation Layer
- **Upstream Relationship**: Replaced AI-style dark theme with flat Material visual design
- **Date**: 2026-08-18

---

## 1. Original Behavior
The application previously used a dark-navy cybersecurity aesthetic (`#0b0f17`, `#111827`, `#1e293b`), glowing neon cyan/blue accents, pill-shaped badges (`border-radius: 9999px`), floating cards with heavy gradients, and large shadows resembling modern SaaS marketing concepts.

## 2. Problem / Reason
1. Looked like an AI-generated SaaS dashboard rather than a simple, clean, professional beginner student academic software project.
2. Excessive rounded corners, pill badges, and dark glows decreased readability and felt over-decorated.
3. The user requested a flat Material-style design system with strong purple accents (`#6200EE`), white surfaces (`#FFFFFF`), light grey page background (`#F5F5F5`), dark charcoal text (`#212121`), rectangular controls (`border-radius: 2px`), and simple hierarchy.

## 3. Planned Change
1. Redesign `style.css` using the flat Material palette:
   - Primary Purple: `#6200EE`
   - Dark Purple: `#3700B3`
   - Primary Text: `#212121`
   - Secondary Text: `#616161`
   - Light Text: `#757575`
   - Page Background: `#F5F5F5`
   - Surface: `#FFFFFF`
   - Border: `#D6D6D6`
   - Light Border: `#E5E5E5`
   - Hover: `#F0EAFB`
   - Semantic colors: Success `#2E7D32`, Warning `#ED6C02`, Danger `#C62828`, Info `#1565C0`
2. Enforce rectangular geometry: `border-radius: 2px` on buttons, inputs, cards, modals; `border-radius: 0px` on tables; zero `9999px` pill shapes.
3. Flatten header to clean white navbar with bottom border.
4. Simplify KPI blocks, 3x3 Risk Matrix heatmap, and severity progress bars.
5. Fix direct HTML route for `/profile` in `app.py`.

## 4. Implementation Details
- Completely rewrote `static/css/style.css` with the flat Material design tokens.
- Updated `templates/index.html` header, fonts (`Roboto`), light body class, and minimal rectangular KPI cards.
- Verified all backend logic, database, models, APIs, and tests remained untouched and 100% functional.
