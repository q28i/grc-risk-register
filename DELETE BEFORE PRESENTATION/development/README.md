# Development & Verification Tooling

This directory contains internal verification suites, audit scripts, and database snapshot utilities used during software engineering.

---

## Contents

- **`test_chg0014_presentation_copy.py`**: Automated presentation copy generator audit.
- **`test_chg0015_presentation_persistence.py`**: 3-stage lifecycle persistence test for Demo Feature Controls.
- **`test_semester2_final_verification.py`**: Full semester 2 submission verification suite.
- **`backup_presentation_db.py`**: Development snapshot utility for SQLite presentation databases.
- **`audit_public_files.py`**: Security scan for leaked credentials, private logs, or forbidden terms.
